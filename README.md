# ADDRESS BOOK MANAGEMENT SYSTEM

**PROJECT OVERVIEW**

A console-based application developed using C to manage contact details. Users can add, search, edit, delete, and display contacts with CSV file storage.

**FEATURES**
- Add, Search, Edit and Delete Contacts
- Display All Contacts
- Phone Number and Email Validation
- Duplicate Contact Checking
- CSV File Handling

**TECHNOLOGIES USED**
- Programming Language: C
- Concepts: Structures, Pointers, Functions, Arrays and Strings
- File Handling: CSV
- Compiler: GCC

**VALIDATION RULES**
- Phone number must contain exactly 10 digits.
- Email must start with a lowercase letter and end with `.com`.
- Exactly one `@` symbol is allowed.
- At least one character must be present between `@` and `.com`.
- Duplicate phone numbers and emails are not allowed.
